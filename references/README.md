# Tài liệu nguồn

Các PDF và sách tham khảo không được đưa trực tiếp vào Git vì chúng là tệp nhị phân lớn, khó diff và có thể chịu điều kiện bản quyền riêng.

Repository chỉ theo dõi:

- danh mục và yêu cầu nguồn trong `docs/source-map.md`;
- trích dẫn/bibliography khi được tạo;
- mã, dữ liệu nhỏ và hình do dự án tạo ra.

Tài liệu gốc được giữ ngoài repository. Khi cần tái tạo môi trường, bổ sung URL chính thức, DOI/arXiv ID và checksum vào manifest thay vì commit toàn bộ PDF.
